## Hi there 👋

This is an organization managed by the [IMCF](www.github.com/imcf) to host Streamlit Community apps. As Streamlit requires read/write access to all repos inside an org,
this organization was created so that specific repositories to be hosted can live here. 

Currently, 2 apps have been deployed:
  * [generate-well-points](https://generate-well-points.streamlit.app/): generates all imaging positions calculated from reference points against a given template file.
  * [lmd7-shape-cutting](https://lmd7-shape-cutting.streamlit.app/): generates an `.xml` file from a QuPath `.geojson` file, with user-annotated shapes and calibration points. The [LMD7](https://www.leica-microsystems.com/products/light-microscopes/p/leica-lmd7/) can then import this and perform the exact shape cutting.
